PRODUCT / CATEGORY IMAGES  (used by the redesigned inner pages)
-----------------------------------------------------------------
Name the file exactly like the page slug (the part before .html):
   sweet-boxes.jpg          -> product "Sweet Boxes"  (tile + main photo)
   sweet-boxes-2.jpg        -> extra gallery photo 2 on the product page
   sweet-boxes-3.jpg        -> extra gallery photo 3 ...
   rigid-boxes.jpg          -> category "Rigid Boxes" (collection card + hero)
Allowed: .webp .jpg .jpeg .png .avif   (lowercase names, letters/numbers/hyphens)
Tip: portrait-ish or square photos, ~1000px wide, under 300 KB each.

If no file is found here, the site uses the image uploaded from Admin.
If neither exists, a soft sage/blush colour tile with a box icon is shown.
